# Amoeba Roguelike Remastered has moved

The game now lives in
**[CassidyPrather/game-prototypes](https://github.com/CassidyPrather/game-prototypes)**,
as one of the prototypes behind its menu. Play it at
<https://wirenook.net/game-prototypes/>. Its docs are in
[`docs/AMOEBA.md`](https://github.com/CassidyPrather/game-prototypes/blob/main/docs/AMOEBA.md).

It moved whole from this repository's `main` at `f66e95c`. Everything up to
that commit is still here in the history: the Rust remaster, and before it
the original C# 7DRL entry (RogueSharp + RLNET). That is why this repository
is archived rather than deleted.

`main` now holds only this note and a GitHub Pages deploy that sends
<https://wirenook.net/amoeba_rl/>, the game's old address, to its new one.

The original 7DRL entry is still on [itch.io](https://vectis.itch.io/amoeba-roguelike).
